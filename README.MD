# Aprende Python - Ejercicios Básicos

Este repositorio contiene una colección de archivos y ejercicios básicos para aprender los fundamentos de Python. Cada archivo aborda un tema específico, ideal para quienes están comenzando en la programación con Python.

## Estructura de archivos

- **01-variables.py**  
  Introducción a variables, tipos de datos básicos: cadenas, enteros, decimales y booleanos.

- **02-strings.py**  
  Manipulación de cadenas: mayúsculas, minúsculas, búsqueda y reemplazo de texto.

- **03-operaciones.py**  
  Operaciones matemáticas básicas: suma, resta, multiplicación, división, potencia y módulo.

- **04-comparacion.py**  
  Comparaciones entre valores: mayor, menor, igual y desigual.

- **05-input.py**  
  Uso de la función `input()` para recibir datos del usuario y tipos de datos resultantes.

- **06-conversion.py**  
  Conversión de tipos de datos, por ejemplo, de cadena a entero.

- **hello-world.py**  
  Primer programa clásico: imprimir "hello-world" en pantalla.

## ¿Cómo usar este repositorio?

1. Clona el repositorio en tu máquina local.
2. Abre los archivos `.py` en tu editor favorito (por ejemplo, Visual Studio Code).
3. Ejecuta cada archivo para ver el resultado y modificar el código para experimentar.

## Requisitos

- Python 3.x instalado en tu sistema.

## Ejecución

Para ejecutar un archivo, usa el siguiente comando en la terminal:

```sh
python nombre-del-archivo.py
```

Por ejemplo:

```sh
python 01-variables.py
```
